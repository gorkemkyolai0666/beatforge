# BeatForge — Mimari

BeatForge, NestJS + Next.js + PostgreSQL ile çalışan müzik keşif intelligence platformudur.

## Backend Modülleri
- auth, boards (Playlistler), sprints (Oturum Döngüleri), issues (Parçalar)
- triage (Taste Drift Intelligence Inbox), cycle-analytics (Dinleme Oturumu Heatmap)
- dependencies (Playlist Cohesion Cascade Radar), ceremonies, organizations
